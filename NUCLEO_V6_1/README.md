# V6.1 — reparo por exemplos em arquivos Python restritos

Protocolo pré-execução: cinco funções novas manuscritas (tarifas, inversão de sinal, estoque limitado, variação acumulada, quota), três sementes, três variantes (limpa, uma e duas mutações), duas políticas pareadas; 90 episódios. Sem usar os oito modelos anteriores como tarefas. A gramática restrita do V6 e seus limites permanecem. Não são issues de repositórios externos. Variantes neutras possíveis. Session recebe apenas código permitido, pool de entradas possíveis e exemplos, nunca referência; benchmark responde pedidos usando implementação de referência separada. As duas políticas compartilham construção de até 256 variantes AST por arquivo, até sete exemplos; consulta inicial idêntica e seguintes fixas ou por diversidade de assinaturas. O mecanismo só emite quando há exemplos e todas hipóteses sobreviventes concordam no pool. Todas as hipóteses são verificadas contra todos os exemplos entregues. Avaliação externa finita de entradas unitárias fora do pool e listas mais longas. Medir acertos, erros, abstenção, exemplos e tempo; construção compartilhada registrada separadamente. Não ajustar após avaliação. As fontes são arquivos reais lidos do disco, preservados por hash, candidatos escritos separadamente, sem execução do código pelo agente. Não se alega generalização a programas Python arbitrários. O oracle só existe no benchmark, não no CLI. V6.1 não usa memória aprendida nem professora; isola interface prática.

## Uso
A partir da raiz do repositório (branch experimento-04):
python3 NUCLEO_V6_1/contract_repair.py --source caminho.py --examples exemplos.json --output NUCLEO_V6_1/minha_execucao

Formato exemplos.json: lista de objetos {"input":[1,2],"output":3}. Pode começar com [].
Se request.json for criado, preencher output esperado e acrescentar aos exemplos, repetir com novo diretório de saída. Se candidate.py for criado, revisar e testar por fora. Não substitui arquivo original. Aceita apenas funções solve(items) com o subconjunto AST descrito no V6. Não usar com fonte hostil ou dados confidenciais. Sem rede/LLM. No benchmark 90 episódios esperados. Resultados arquivados permanentemente.
