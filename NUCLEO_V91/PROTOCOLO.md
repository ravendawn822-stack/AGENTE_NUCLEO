# V91 — linguagem simbólica finita
Pré-registro V91–V96. DSL de transformação de um acumulador inteiro: inc, neg, double, half (divisão piso), mod3, abs; controle condicional par/negativo e repetição literal de 2 ou 3 vezes. AST declarativa em JSON: bloco é sequência de instruções; controle tem subblocos; entrada é acumulador, saída é valor final. Limites externos: entrada/valor intermediário em [-4096,4096], até 32 nós, profundidade máxima 4, combustível de execução 64; repetir apenas literal. Sem acesso a arquivos, rede, processos, reflexão, execução arbitrária, alteração de código ou permissões. Testar aceitação/rejeição estrutural. O protocolo cobre linguagem de domínio pequeno, não programação geral.
