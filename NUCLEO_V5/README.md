# NUCLEO_V5 — contrato por exemplos, sem oráculo dentro do agente

Protocolo pré-execução. A interface propose recebe apenas lista de exemplos JSON (input: lista de inteiros, output: inteiro), biblioteca já construída e política. Não recebe função de referência, rótulo, parâmetros ocultos, nem acesso externo. Solicita lotes explícitos de exemplos faltantes (observações iniciais, subobjetivos de estado, guarda), recebe novas linhas e reavalia. Se faltarem dados, não inventa respostas. O ambiente de benchmark responde às solicitações artificialmente; usuário real precisará fornecer dados. Limites: 450 exemplos, 5 lotes, valores inteiros, listas até 32; mesmo catálogo de estados do V4.1, sem planejamento aberto. Nenhuma memória é alterada na avaliação. A interface aceita somente exemplos e gera código através do compilador numérico allowlist; nunca executa texto arbitrário ou edita fonte anterior. A rotina real Python usa acumulador, estado discreto e regras inferidas, pode ser usada separadamente. Validação finita, não prova equivalência geral.

Quatro novas sementes, cinco casos por seis famílias em cada (120 casos, 4 políticas, 480 episódios). Excluir assinaturas finitas de V4.1 e duplicatas novas; não se exclui coincidência com todos os experimentos. fixed: somente modelo sem estado, biblioteca com memória e aula. primitive: estados adaptativos e gramática sem memória. memory: estados adaptativos e memória V3/V3.1 + aula shape V4. dense: mesma biblioteca, observações densas solicitadas. Mesmos exemplos acessíveis e validação reservada, quantidade solicitada é métrica e limitada, não se afirma igualdade de tempo. A aquisição histórica e construção dos índices são custos separados. O benchmark entrega exclusivamente exemplos solicitados, informações do avaliador só depois que o agente decide. O agente confere todos os exemplos fornecidos antes de emitir candidato. Exportar TODOS os candidatos da política memory, inclusive errados, para execução por avaliador externo que regenera a fonte a partir de AST restrita, confere igualdade de bytes e verifica equivalência ao intérprete e acerto no mesmo conjunto reservado. A exportação não é teste adicional independente. Sem LLM, rede ou execução de código arbitrário pelo agente.

Uso local: a partir da raiz da branch experimento-04, obter as duas memórias arquivadas em diretório separado. Entrada JSON de objetos {"input":[1,2],"output":3}. Comando:
python3 NUCLEO_V5/contract.py --examples exemplos.json --prior CAMINHO/memories.json --banks CAMINHO/banks.json --output NUCLEO_V5/minha_execucao
Saída result.json, requests.json quando precisa de exemplos (preencher outputs corretos e somar à entrada, usar novo diretório na próxima rodada) ou solution.py quando houver candidato consistente. Para avaliação real, testar com dados inéditos. Não abrir solução como prova de correção. A versão é genérica apenas dentro da gramática de reduções numéricas deste projeto, não resolve software real arbitrário.
